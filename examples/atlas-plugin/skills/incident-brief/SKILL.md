# Atlas 事件简报

当用户提供事件记录、时间线或一系列观察结果，需要整理成清晰的事件简报时，使用此技能。

1. 阅读 [`references/template.md`](references/template.md)。
2. 保留时间戳，并区分事实与假设。
3. 先说明用户影响，再提及内部实现细节。
4. 除非有证据支持，否则不要指定根本原因。
5. 为每项后续行动指定负责人，或明确标记为未分配。

如果缺少关键证据，列出完成简报所需的最少问题集。
