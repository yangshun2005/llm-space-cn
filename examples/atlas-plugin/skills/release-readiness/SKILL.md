# Atlas 发布就绪检查

当用户询问某个发布版本是否已就绪、请求发布检查清单，或提供发布证据以供审查时，请使用此技能。

1. 阅读 [`references/checklist.md`](references/checklist.md)。
2. 确定所声称的版本、渠道和目标平台。
3. 将提供的证据映射到每个检查清单项。
4. 将阻塞项与后续改进项区分开。
5. 切勿虚构通过的测试、签名、部署或审批。

返回一个简洁的结论，随后列出已通过项、阻塞项，以及每个阻塞项的下一个验证命令或负责人。
