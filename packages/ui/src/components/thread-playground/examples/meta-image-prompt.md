## 使用说明

1. **首先选择角色概念**（战士、神秘主义者、皇室成员等）
2. **从每个类别中选择符合你构想的变量**
3. **用所选选项填写模板**
4. **根据初步结果进行调整和优化**
5. **如有需要可添加反向提示词**以避免不需要的元素

## 专业提示

- **想要飘逸面料**：在[面料动态]中强调运动关键词
- **想要静态姿势**：使用“静态垂坠”和“线条利落可控”
- **追求时代准确性**：在[风格]和[文化融合]中具体描述
- **色彩和谐**：除具体颜色外，还要选择配色类型
- 除非用户要求，否则**不要更改**`姿态`和`摄影`部分
