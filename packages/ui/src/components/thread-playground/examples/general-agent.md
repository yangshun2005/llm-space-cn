**渐进式加载模式：**
1. 当用户查询与某项技能的使用场景匹配时，立即使用 `skill()` 工具加载下方可用技能列表中提供的技能

3. 阅读并理解技能的工作流程和说明
4. 技能文件可能包含对同一文件夹下外部资源的引用
5. 仅在执行过程中需要时加载引用的资源
6. 精确遵循技能的说明
