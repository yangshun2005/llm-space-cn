# 设置

设置是 LLM Space 的全局配置中心。它管理应用程序外观、默认模型、模型提供商、MCP 服务器、内置搜索工具和技能发现文件夹。

![从菜单打开设置](./images/settings-00-entry.png)

# 如何打开设置

在 macOS 菜单栏中，点击 `LLM Space`，或在开发版本中点击 `LLM Space-dev`，然后选择 `设置...`。

你也可以使用快捷键：

```text
Command + ,
```

设置打开后，左侧显示类别，右侧显示所选类别的配置表单。本文档涵盖以下内容：

| 页面 | 用途 |
| --- | --- |
| 通用 | 配置语言、外观、默认模型、工作区文件夹和匿名分析。 |
| 模型 | 添加和管理模型提供商，启用或禁用模型，以及添加自定义模型。 |
| MCP | 添加和测试 MCP 服务器，以便线程可以使用外部 MCP 工具。 |
| 搜索 | 配置内置 `web_search` 和 `web_fetch` 工具使用的搜索服务。 |
| 技能 | 配置内置 `skill()` 工具使用的技能发现文件夹。 |

# 通用

通用页面配置应用级默认设置。

![通用设置页面](./images/settings-01-general.png)

| 设置 | 描述 |
| --- | --- |
| 语言 | 界面语言。支持英语（美国）和中文；选择会持久保存，新会话会跟随该设置。原生菜单跟随操作系统显示语言。 |
| 外观 | 应用主题。可匹配系统设置，或强制使用浅色或深色模式。 |
| 主题色 | 用于按钮、链接和高亮显示的强调色。 |
| 渲染 | 消息渲染模式。`完整` 使用完整编辑器渲染消息；`快速` 显示纯文本，以便在大型线程中更流畅地滚动。 |
| 默认模型 | 用于新线程的模型。当线程保存的模型不再可用时，也用作回退模型。 |
| 工作区文件夹 | 当前工作区目录，线程文件存储于此。点击路径可在系统文件管理器中打开。 |
| 共享匿名使用分析 | 是否共享匿名使用数据。匿名数据仅包含产品操作，绝不包含提示词、消息或 API 密钥。 |

## 默认模型

`默认模型` 可以是特定的已启用模型，也可以保持为 `自动`。

- 选择特定模型：新线程默认使用该模型。
- 选择 `自动`：LLM Space 自动从当前可用的模型中选择。

如果新建的线程一直使用非预期的模型，请先检查默认模型设置。

## 工作区文件夹

`工作区文件夹` 显示线程文件的存储位置。默认情况下，它位于：

```text
~/.llm-space/workspace
```

该目录下的每个 `.json` 文件对应一个线程。有关线程文件格式的更多详细信息，请参阅 [核心概念](./core-concepts.md)。

# 模型

模型页面管理模型提供商和模型列表。线程选择的模型来自此处配置并启用的模型提供商。

![模型设置页面](./images/settings-02-models.png)

## 添加提供商

点击左下角的 `添加提供商` 来添加模型提供商。

![添加提供商菜单](./images/settings-03-add-provider.png)

提供商菜单通常分为以下几组：

| 分组 | 描述 |
| --- | --- |
| 自定义 | 添加自定义提供商。用于兼容 OpenAI、Anthropic 或 Responses API 的第三方服务。 |
| 已发现 | LLM Space 在本地环境变量中检测到 API 密钥的提供商。 |
| 推荐 | 推荐的常用内置提供商。 |
| 内置 | 其他内置提供商。 |

添加内置提供商后，右侧会显示 API 密钥、Base URL、模型列表及相关设置。

## 配置内置提供商

模型页面右侧显示所选提供商的配置。内置提供商通常包括：

| 设置 | 描述 |
| --- | --- |
| API 密钥 | 提供商的 API 密钥。可直接输入或引用环境变量。 |
| 自定义 Base URL | 是否使用自定义 API 端点。禁用时，使用提供商默认端点。 |
| 模型 | 此提供商下的模型。您可以单独启用或禁用模型。 |

API 密钥可以引用环境变量。例如：

```text
"$OPENAI_API_KEY"
```

如果 API 密钥留空，LLM Space 会尝试使用提供商的官方环境变量。

## 添加自定义提供商

如果您的模型服务兼容 OpenAI、Anthropic 或 OpenAI Responses API，您可以添加自定义提供商。

![自定义提供商设置页面](./images/settings-05-custom-provider.png)

常见的自定义提供商设置：

| 设置 | 描述 |
| --- | --- |
| 名称 | 提供商显示名称。 |
| API 类型 | API 兼容类型，如 OpenAI Completions、Anthropic Messages 或 OpenAI Responses。 |
| 图标 | 提供商图标关键字。留空则让 LLM Space 按名称自动匹配。 |
| API 密钥 | 调用此提供商所需的 API 密钥。 |
| Base URL | API 服务端点。自定义提供商必填。 |
| 请求头 | 额外的 HTTP 请求头。适用于特殊认证或网关参数。 |

## 添加自定义模型

在提供商的 `模型` 区域中，点击添加按钮来添加自定义模型。

![添加自定义模型对话框](./images/settings-06-custom-model.png)

常见的自定义模型字段：

| 字段 | 描述 |
| --- | --- |
| 模型 ID | 提供商 API 使用的实际模型 ID。 |
| 模型名称 | 在 LLM Space 中显示的模型名称。 |
| 图标 | 模型图标关键字。 |
| API 类型 | 此模型使用的 API 兼容类型。 |
| 支持推理 | 模型是否支持推理参数或推理能力。 |
| 使用 DeepSeek 思考格式 | 是否使用 DeepSeek 风格的思考格式。 |
| 支持图像 | 模型是否支持图像输入。 |
| 上下文窗口 | 上下文窗口大小。 |
| 最大令牌数 | 最大输出令牌数。 |

配置完成后，该模型会出现在线程模型选择器中。

## 启用、禁用和移除

模型页面还允许您：

- 在模型列表中启用或禁用单个模型。
- 从模型列表菜单中批量启用或禁用模型。
- 从提供商列表项菜单中移除提供商。
- 编辑自定义模型，或删除不再需要的自定义模型。

移除提供商不会删除现有的线程文件。如果线程引用了已移除的模型，应用会在运行时回退到可用模型或默认模型。

# MCP

MCP 页面用于连接 MCP 服务器。服务器连接后，其工具可以添加到线程的工具中，以便模型可以通过 MCP 调用外部能力。

## 添加 MCP 服务器

点击 `服务器` 列表右上角的 `+` 来创建新的 MCP 服务器。

![新建 MCP 服务器表单](./images/settings-07-mcp-new.png)

MCP 服务器设置：

| 设置 | 描述 |
| --- | --- |
| 名称 | 服务器显示名称。LLM Space 会从中生成工具前缀。 |
| 传输方式 | 连接类型。支持 `stdio`、`Streamable HTTP` 和 `SSE`。 |
| 命令 | 在 `stdio` 模式下用于启动 MCP 服务器的命令。 |
| 参数 | 在 `stdio` 模式下传递给命令的参数，每行一个参数。 |
| 工作目录 | `stdio` 模式下的工作目录。 |
| 环境变量 | 在 `stdio` 模式下传递给进程的环境变量。 |
| URL | `Streamable HTTP` 或 `SSE` 模式的远程 MCP 端点。 |
| 请求头 | 远程 MCP 请求的额外 HTTP 请求头。 |

配置完成后，点击 `保存`。

## 测试 MCP 服务器

保存后，点击 `连接并测试`。LLM Space 会连接到 MCP 服务器并尝试列出其公开的工具。

![保存后的 MCP 服务器，显示连接并测试](./images/settings-08-mcp-test.png)

测试结果显示在服务器详情上方：

| 状态 | 含义 |
| --- | --- |
| 未测试 | 已保存，但尚未测试。 |
| 已连接 | 连接成功并已加载工具列表。 |
| 失败 | 连接或协议握手失败。请检查配置。 |

测试成功后，您可以在线程的工具区域添加这些 MCP 工具。MCP 工具名称通常包含服务器前缀，例如：

```text
mcp__tavily__search
```

# 搜索

搜索页面配置内置 `web_search` 和 `web_fetch` 工具使用的搜索服务。

**注意：搜索设置仅适用于内置的 `web_search` 和 `web_fetch` 工具。** 它们不影响模型提供商、MCP 工具或正常的线程模型调用。

![搜索设置页面](./images/settings-09-search.png)

支持的搜索提供商：

| 提供商 | 描述 |
| --- | --- |
| Firecrawl | 默认搜索提供商。需要 Firecrawl API 密钥。 |
| Tavily | 可选搜索提供商。需要 Tavily API 密钥。 |

此页面上的 API 密钥支持两种形式：

```text
直接输入 API 密钥
```

或引用环境变量：

```text
$FIRECRAWL_API_KEY
$TAVILY_API_KEY
```

如果您的线程未启用 `web_search` 或 `web_fetch` 工具，则运行期间不会使用此处的提供商和 API 密钥设置。

# 技能

技能页面为内置的 `skill()` 工具配置发现文件夹。线程启用 `skill()` 工具后，模型可以请求从这些文件夹加载技能。

**注意：技能设置仅适用于内置的 `skill()` 工具。** 它们不影响 MCP 工具、自定义函数工具，也不会自动将技能作为常规工具添加到线程中。

![技能设置页面](./images/settings-10-skills.png)

## 技能发现文件夹

左侧列出技能发现文件夹。LLM Space 扫描这些文件夹，并在右侧显示每个技能的名称、描述和启用状态。

默认文件夹通常包括：

```text
~/.claude/skills
~/.codex/skills
~/.agents/skills
```

也可能包含由 LLM Space 管理的技能文件夹。

## 添加和移除文件夹

点击 `添加文件夹` 来添加新的技能文件夹。

该文件夹必须遵循技能结构约定：每个技能是一个包含 `SKILL.md` 的子目录。

示例：

```text
my-skills/
  deep-research/
    SKILL.md
  writing-assistant/
    SKILL.md
```

您可以从文件夹项的菜单中移除文件夹。移除文件夹仅将其从 LLM Space 的发现列表中移除；不会删除磁盘上的实际文件。

## 启用和禁用技能

右侧列表中的每个技能都有自己的开关：

- 开启：`skill()` 工具可以发现并使用此技能。
- 关闭：技能被隐藏，不会提供给 `skill()` 工具。

文件夹项菜单还支持 `启用所有技能` 和 `禁用所有技能`。

# 设置存储位置

大多数设置保存在本地数据目录下：

```text
~/.llm-space/settings
```

常见文件：

| 文件 | 内容 |
| --- | --- |
| `models.json` | 模型提供商、API 密钥引用、Base URL、自定义模型和模型启用状态。 |
| `mcp.json` | MCP 服务器配置。 |
| `search.json` | 搜索提供商和搜索 API 密钥配置。 |
| `skills.json` | 技能发现文件夹和隐藏状态。 |
| `analytics.json` | 匿名分析设置和匿名安装 ID。 |
| `window.json` | 桌面窗口位置、大小、缩放及相关状态。 |

如果设置行为异常，请先备份整个 `~/.llm-space` 目录，然后检查相应的 JSON 文件。
