# 共享线程

共享功能会发布线程的只读副本，其他人可以在浏览器或 LLM Space 中打开该副本。源线程保留在其原始工作区中，不会被修改。

## 要求

- 桌面应用必须能够访问 GitHub。
- 发布前必须登录 GitHub。如果已退出登录，共享流程会请求确认，然后启动 GitHub 设备流程。
- 如果线程属于某个远程运行时，则必须连接该运行时。

## 如何共享

1. 打开线程。
2. 在线程标题栏中打开**更多操作**（`...`）。
3. 选择**共享线程**。
4. 查看或编辑标题，并可选择添加描述。这些值仅影响共享副本。
5. 选择**生成链接**。如果出现提示，请完成 GitHub 登录；之后发布将自动恢复。
6. 复制生成的链接或在浏览器中打开。

每次发布操作都会创建一个新的共享链接。关闭对话框或发布失败不会更改本地线程。

## 查看者会看到什么

该链接会打开静态 LLM Space Web 查看器。它会以只读方式渲染完整的共享线程，包括提示词、消息、工具调用及其他持久化的线程数据。查看者无需 GitHub 账户。页面还提供**在 LLM Space 中打开**选项，当应用已安装时，可通过桌面深度链接打开同一共享线程。

发布前，LLM Space 会解析线程的有效模型，并将其显示名称存储在共享副本中。这样，即使 Web 查看器无法访问发布者的本地提供商设置，也能显示正确的模型。

## 隐私与 GitHub Gists

共享线程以**秘密 GitHub Gist** 形式存储。秘密 Gist 不会公开列出，也不会出现在公共搜索中，但它并非私有：任何拥有 URL 的人都可以读取和转发。

共享前请查看线程内容。请勿发布 API 密钥、凭据、私有源代码、个人数据或其他敏感内容。标题和描述也会发送到 GitHub。如需撤销访问权限，请从 GitHub 账户中删除该 Gist；已复制或下载的版本无法召回。

## 实现细节

- 桌面端从其所属运行时读取线程，因此本地和远程线程的所有权得以保留。
- 共享副本接收可选的标题和解析后的模型元数据，而不会修改源文件。
- `GistThreadWriter` 通过 GitHub API 创建秘密 Gist。
- 返回的浏览器 URL 指向静态 LLM Space 查看器上的 `#/shared/gist/threads/<gistId>`。
- Web 查看器使用 `GistThreadReader`，并以展示性只读模式渲染结果。

相关实现文件包括 `apps/desktop/src/components/share-thread-dialog.tsx`、`apps/desktop/src/bun/rpc/share-thread.ts` 和 `packages/core/src/storage/gist/`。

## 故障排除

- **登录无法完成：** 取消并重试 GitHub 设备流程，然后确认可通过配置的代理访问 GitHub。
- **运行时未连接：** 共享前请重新连接拥有该线程的运行时。
- **剪贴板不可用：** 手动选择并复制可见的 URL。
- **链接不应再有效：** 从 GitHub 中删除对应的秘密 Gist。
