# 深度研究技能

## 概述

本技能提供了一种进行深入网络研究的系统方法论。**在开始任何内容生成任务之前加载此技能**，以确保从多个角度、深度和来源收集足够的信息。

## 核心原则

**切勿仅基于通用知识生成内容。** 输出的质量直接取决于事先研究的质量和数量。单一的搜索查询永远不够。

## 研究方法

### 阶段 0：澄清（可选）

在开始研究之前，如有必要，请向用户询问主题的澄清信息：

1. **向用户询问澄清信息**：使用 `ask_user_question` 询问主题的澄清信息。

### 阶段 1：广泛探索

从广泛搜索开始，以了解整体情况：

1. **初步调查**：搜索主要主题以了解整体背景
2. **识别维度**：从初步结果中，识别需要深入探索的关键子主题、主题、角度或方面
3. **绘制领域地图**：注意存在的不同观点、利益相关者或视角

示例：
```
主题：“AI 在医疗保健中的应用”
初步搜索：
- “AI 医疗保健应用 2024”
- “人工智能医学诊断”
- “医疗保健 AI 市场趋势”

识别出的维度：
- 诊断 AI（放射学、病理学）
- 治疗推荐系统
- 行政自动化
- 患者监测
- 监管环境
- 伦理考量
```

### 阶段 2：深入探究

针对识别出的每个重要维度，进行有针对性的研究：

1. **具体查询**：为每个子主题使用精确关键词进行搜索
2. **多种表述**：尝试不同的关键词组合和表述方式
3. **获取完整内容**：使用 `web_fetch` 完整阅读重要来源，而不仅仅是摘要
4. **追踪引用**：当来源提到其他重要资源时，也搜索这些资源

示例：
```
维度：“放射学中的诊断 AI”
针对性搜索：
- “AI 放射学 FDA 批准的系统”
- “胸部 X 光 AI 检测准确性”
- “放射学 AI 临床试验结果”

然后获取并阅读：
- 关键研究论文或摘要
- 行业报告
- 实际案例研究
```

### 阶段 3：多样性与验证

通过寻求多样化的信息类型来确保全面覆盖：

| 信息类型 | 目的 | 示例搜索 |
|-----------------|---------|------------------|
| **事实与数据** | 具体证据 | “统计数据”、“数据”、“数字”、“市场规模” |
| **示例与案例** | 实际应用 | “案例研究”、“示例”、“实施” |
| **专家观点** | 权威视角 | “专家分析”、“访谈”、“评论” |
| **趋势与预测** | 未来方向 | “2024 年趋势”、“预测”、“未来” |
| **比较** | 背景与替代方案 | “对比”、“比较”、“替代方案” |
| **挑战与批评** | 平衡视角 | “挑战”、“局限性”、“批评” |

### 阶段 4：综合检查

在继续内容生成之前，请验证：

- [ ] 我是否至少从 3-5 个不同角度进行了搜索？
- [ ] 我是否完整获取并阅读了最重要的来源？
- [ ] 我是否拥有具体的数据、示例和专家观点？
- [ ] 我是否同时探讨了积极方面和挑战/局限性？
- [ ] 我的信息是否是最新的且来自权威来源？

**如果任何答案为“否”，请在生成内容之前继续研究。**

## 搜索策略技巧

### 有效的查询模式

```
# 具体化并附带上下文
❌ “AI 趋势”
✅ “2024 年企业 AI 采用趋势”

# 包含权威来源提示
“[主题] 研究论文”
“[主题] 麦肯锡报告”
“[主题] 行业分析”

# 搜索特定内容类型
“[主题] 案例研究”
“[主题] 统计数据”
“[主题] 专家访谈”

# 使用时间限定词 — 始终使用 <current-date> 中的实际当前年份
“[主题] 2026”   # ← 替换为真实的当前年份，切勿硬编码过去的年份
“[主题] 最新”
“[主题] 近期发展”
```

### 时间感知

**在形成任何搜索查询之前，务必检查上下文中的 `<current-date>`。**

`<current-date>` 提供完整日期：年、月、日和星期（例如 `2026-02-28，星期六`）。根据用户的询问使用适当的精度级别：

| 用户意图 | 所需时间精度 | 示例查询 |
|---|---|---|
| “今天 / 今早 / 刚发布” | **月 + 日** | `“2026 年 2 月 28 日科技新闻”` |
| “本周” | **周范围** | `“2026 年 2 月 24 日当周技术发布”` |
| “最近 / 最新 / 新” | **月** | `“2026 年 2 月 AI 突破”` |
| “今年 / 趋势” | **年** | `“2026 年软件趋势”` |

**规则：**
- 当用户询问“今天”或“刚发布”时，请在搜索查询中使用 **月 + 日 + 年** 以获取当天的结果
- 当需要日级精度时，切勿降级为仅年份 — `“2026 年科技新闻”` 不会显示今天的新闻
- 尝试多种表述：数字形式（`2026-02-28`）、文字形式（`2026 年 2 月 28 日`）以及相对术语（`今天`、`本周`）在不同查询中使用

❌ 用户询问“今天科技界有什么新动态” → 搜索 `“2026 年新技术”` → 错过今天的新闻
✅ 用户询问“今天科技界有什么新动态” → 搜索 `“2026 年 2 月 28 日新技术”` + `“2 月 28 日今日科技新闻”` → 获取今天的结果

### 何时使用 web_fetch

在以下情况下使用 `web_fetch` 阅读完整内容：
- 搜索结果看起来高度相关且权威
- 您需要超出摘要的详细信息
- 来源包含数据、案例研究或专家分析
- 您想了解某个发现的完整背景

### 迭代优化

研究是迭代的。在初步搜索之后：
1. 回顾您已了解的内容
2. 识别理解中的空白
3. 制定新的、更有针对性的查询
4. 重复直到您拥有全面的覆盖

## 质量标准

当您能够自信地回答以下问题时，您的研究就足够了：
- 关键事实和数据点是什么？
- 2-3 个具体的实际示例是什么？
- 专家对此主题有何看法？
- 当前的趋势和未来方向是什么？
- 挑战或局限性是什么？
- 是什么使该主题现在具有相关性或重要性？

## 需要避免的常见错误

- ❌ 仅进行 1-2 次搜索后就停止
- ❌ 仅依赖搜索摘要而不阅读完整来源
- ❌ 仅搜索多面主题的一个方面
- ❌ 忽略矛盾的观点或挑战
- ❌ 在存在当前数据时使用过时信息
- ❌ 在研究完成之前开始内容生成

## 输出

完成研究后，您应具备：
1. 从多个角度对主题的全面理解
2. 具体的事实、数据点和统计数据
3. 实际示例和案例研究
4. 专家观点和权威来源
5. 当前趋势和相关背景

**只有在此之后才能进行内容生成**，利用收集到的信息创建高质量、充分知情的内容。
